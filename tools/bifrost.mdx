Bifrost was evaluated as an OpenAI-compatible HTTP gateway for routing AI requests from workstation tools to OpenAI, Gemini, OpenRouter, and local MLX inference. It is not part of the current stack.

- **GitHub:** https://github.com/maximhq/bifrost
- **Homepage:** https://www.getmaxim.ai/bifrost

## Current path

The [LiteLLM router pool](/local-llm/homelab-gpu) handles multi-provider routing today. Workstation tools call local MLX directly or route through LiteLLM.
